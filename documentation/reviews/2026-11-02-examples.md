## Findings and changes

- The scripted research plan still created the flat worker graph. It now uses
  the existing squad API for a real nested hierarchy and reuses it on subsequent
  tasks. Existing-worker ownership scenarios remain supported.
- The CLI AI demo inspected the old flat helper location. It now inspects the
  actual nested squad through native domain actions. Its live deadline now
  matches the playground's one-hour budget instead of three minutes.
- The CLI team demo supplied an unnecessary stamp-label context that the
  browser-only scope adapter deliberately rejects during child activation. That
  team-only label is removed; the single-agent context example remains. Scope
  admission rules are unchanged and their negative cases remain tested.
- Native list could encounter an exiting registry member with DurableServer's
  documented normal retirement exit envelope (`:normal`, `:permanent`, or
  `:delete`). It now omits that retiring
  entry while retaining healthy records. Timeouts and unexpected exits retain
  the native typed unavailable error.
- The root page no longer requests a missing favicon. Credential documentation
  now correctly states that the encrypted settings survive server restarts.
